# ProstoJPG Free: установка по просьбе пользователя

Если пользователь пишет «Установи https://github.com/<owner>/ProstoJPG-Free/»,
прочитайте INSTALL.md и выполните команды установки для текущего клиента.
В Codex: `codex plugin marketplace add`, `codex plugin add`.
В Claude Code: `claude plugin marketplace add`, `claude plugin install`.
Второй клиент без отдельной просьбы не устанавливайте.

Плагин не требует входа в ChatGPT, API-ключей и подписок: генерация идёт
встроенным инструментом генерации изображений текущего агента. Если у клиента
такого инструмента нет — сообщите это прямо, не подменяйте генерацию апскейлом
исходника или заглушками.

Проверка после установки: `python3 scripts/cards.py --help` и
`python3 scripts/cards.py prepare ...` на тестовых фото. Успех подтверждается
ответом клиента, а не прочитанной ссылкой. После установки предложите новый чат,
чтобы обновился список навыков. Установка расширения для браузера не требуется:
фото можно загрузить в чат напрямую.
