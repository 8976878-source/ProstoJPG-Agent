# Обработка и сохранение фото (ПростоJPG-Агент)

## Что делает генератор, а что скрипт

| Шаг | Кто делает | Нужен интернет / логин |
|---|---|---|
| Распаковка исходников, расчёт размеров, `job.json` | `cards.py prepare` | нет / нет |
| Создание изображения по промпту | инструмент генерации изображений агента | по правилам клиента / **нет аккаунта ChatGPT** |
| Пропорции, поля, ≥2048 px (2K), сохранение | `cards.py export` | нет / нет |

## Правила результата

- Соотношение сторон каждого фото — как у оригинала (`target_size` в `job.json`).
- Короткая сторона не меньше `--min-side` (по умолчанию 2048 px, 2K).
- Если генератор вернул другую пропорцию, добавляются **белые поля**; товар не
  обрезается и не растягивается.
- Готовые фото выдаются отдельными файлами (`out/card-NN.jpg`), без ZIP.
- Видео не генерируются.
- Исходники и результат остаются на компьютере пользователя. Никакие внешние
  сервисы, ключи и подписки плагин не использует; изображения уходят только в тот
  инструмент генерации, который уже есть у клиента (у Arena — её собственный).

## Диагностика

- `python3 scripts/cards.py info --job-dir job` — состояние задания.
- «нет задания» → сначала `prepare`.
- «в папке generated пусто» → генератор ещё не вернул файлы; имена `NN.png`.
- «короткая сторона ... МАЛО» → поднимите `--min-side` при повторном `export`
  не требуется: `export` сам добивает размер; если мало — проверьте, что
  генератор вернул файл целиком, а не превью.
- Нет Pillow → `pip install "Pillow>=10.4"`.
